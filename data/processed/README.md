Processed intermediate files generated by the pipeline.

Not tracked by git.

## Pipeline Stage Overview

Raw tweets → Cleaning → User Filtering → Reply Chain → PCA Scoring → 

This folder stores the outputs after each major preprocessing step.

## Files

### `clean_tweets.jsonl`
- **Generated by**: `cleaning/tweet_cleaning.py`
- **Description**:  
  Cleaned tweets after text normalization and near-duplicate removal.
- **Only Used by**:
  - User filtering

  *This file is not for clustering*

---

### `dropped_duplicates.jsonl`
- **Generated by**: `cleaning/tweet_cleaning.py`
- **Description**:  
  Tweets removed due to near-duplicate detection (Jaccard similarity).
- **Purpose**:
  - Debugging
  - Visualization
  - Reporting data reduction

---

### `filtered_tweets.jsonl`
- **Generated by**: `cleaning/user_filtering_and_replychain.py`
- **Description**:  
  Tweets from selected users after minimum tweet count filtering and within-user deduplication.
- **Used by**:
  - Reply chain construction
  - PCA scoring
  - Clustering
  - Persona generation
- **File format**:
  Recorded in cleaning/filtered_tweets_format.md

---

### `reply_chain.jsonl`
- **Generated by**: `cleaning/user_filtering_and_replychain.py`
- **Description**:  
  Reply relationships among retained tweets, including root tweet and reply depth.
- **Used by**:
  - Topic clustering
  - Conversation structure analysis
- **File format**:
  Recorded in cleaning/reply_chain_format.md
---

### `tweet_popularity_scores.csv` 
- **Generated by**: `pca/tweet_popularity_pca.py`
- **Description**:  
  PCA-based popularity score for each tweet based on engagement features.
- **Used by**:
  - Selecting representative tweets per topic
- **File format**:
  
| Column            | Type    | Description |
|-------------------|---------|-------------|
| tweet_id          | string  | Unique identifier of the tweet |
| author_id         | string  | Twitter user ID of the tweet author |
| clean_text        | string  | Cleaned tweet text after preprocessing |
| likes             | int     | Number of likes |
| retweets          | int     | Number of retweets |
| replies           | int     | Number of replies |
| quotes            | int     | Number of quote tweets |
| views             | int     | Number of views |
| popularity_score  | float   | Final popularity score computed via PCA |


---

### `cluster_assignments.jsonl`
- **Format**: One JSON object per line: `{"tweet_id": "...", "cluster_id": 0}`
- **Used by**: Persona generation pipeline
- **Note**: A sample file is provided for testing. Replace with real clustering output from the clustering step. See `persona_generation/CLUSTERING_INPUT_SPEC.md` for the contract.

### `cluster_topics.json`
- **Format**: JSON object mapping cluster ID (string) to topic description: `{"0": "...", "1": "..."}`
- **Used by**: Persona generation pipeline


---

## Notes

  1. `cleaning/tweet_cleaning.py`
  2. `cleaning/user_filtering_and_replychain.py`
  3. `pca/tweet_popularity_pca.py`
  4. [clustering file]
  5. 'persona_generation/user_persona_pipeline.py`
